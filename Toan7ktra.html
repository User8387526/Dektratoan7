Bài 1

Tập hợp các số hữu tỉ

Q = { a/b | a,b ∈ Z ; b ≠ 0 }

Số hữu tỉ là số viết được dưới dạng phân số.

Câu 1 — Số nào là số hữu tỉ?

−3 ; 2/5 ; 0 ; 1,25 ; √2

✓ −3, 2/5, 0 và 1,25 là số hữu tỉ.
✗ √2 không phải số hữu tỉ.
Câu 2 — Tìm số đối

5/7 ; −11/6 ; 0

✓ Số đối lần lượt:
−5/7 ; 11/6 ; 0.
Câu 3 — So sánh −3/7 và −4/9

−3/7 = −27/63

−4/9 = −28/63

✓ Vì −27 > −28 nên:
−3/7 > −4/9
Câu 4 — Sắp xếp tăng dần

−1/2 ; 3/4 ; −5/6 ; 0 ; 1/3

✓
−5/6 < −1/2 < 0 < 1/3 < 3/4
Bài 2

Cộng, trừ, nhân, chia số hữu tỉ

a/b : c/d = a/b × d/c
Câu 1 — −7/8 + 5/12
Quy đồng mẫu 24:
−21/24 + 10/24

= −11/24
Câu 2 — 5/6 − (−7/9)
= 5/6 + 7/9

= 15/18 + 14/18

= 29/18
Câu 3 — (−14/15) × 25/21
Rút gọn: 14/21 = 2/3
25/15 = 5/3

= −2/3 × 5/3
= −10/9
⭐ Câu 4 — Tính nhanh

3/7 − 5/11 + 4/7 + 5/11

= (3/7 + 4/7) + (−5/11 + 5/11)

= 1 + 0
= 1
Bài 3

Lũy thừa của số hữu tỉ

aᵐ × aⁿ = aᵐ⁺ⁿ

aᵐ : aⁿ = aᵐ⁻ⁿ

(aᵐ)ⁿ = aᵐⁿ
Câu 1 — (2/3)³
= 2³/3³
= 8/27
Câu 2 — (−3/5)²
= (−3)²/5²
= 9/25
⚠️ Câu 3 — Cẩn thận dấu ngoặc

−(2/3)² và (−2/3)²

−(2/3)² = −4/9

(−2/3)² = 4/9

⚠️ Hai kết quả khác nhau!
🔥 Câu 4 — 2⁵ × 2³ : 2⁶
= 2⁵⁺³⁻⁶
= 2²
= 4
Bài 4

Thứ tự phép tính — Quy tắc chuyển vế

Ngoặc → Lũy thừa → Nhân/Chia → Cộng/Trừ
Câu 1 — 1,2 − 3² + 7,5 : 3
= 1,2 − 9 + 2,5
= −5,3
Câu 2 — 9,8 + 1,5×6 + (6,8−2):3
= 9,8 + 9 + 4,8 : 3
= 9,8 + 9 + 1,6
= 20,4
Câu 3 — Tìm x: x + 5/7 = 12/7
Chuyển 5/7 sang vế phải:
x = 12/7 − 5/7
x = 1
🔥 Câu 4 — x/3 + x/2 = 5/6
2x/6 + 3x/6 = 5/6
5x = 5
x = 1
Hình 8

Góc ở vị trí đặc biệt — Tia phân giác

Góc kề bù → tổng 180°

Góc đối đỉnh → bằng nhau

Tia phân giác → chia góc thành 2 góc bằng nhau
Câu 1 — Góc kề bù 65°
Góc còn lại:
180° − 65°
= 115°
Câu 2 — Góc đối đỉnh 72°
Góc đối đỉnh bằng nhau.
= 72°
Câu 3 — Tia phân giác của góc 86°
86° : 2 = 43°

Mỗi góc nhỏ bằng 43°.
🔥 Câu 4 — Bài tìm x

Oz là tia phân giác.
xOz = 3zOy − 20°.

Vì Oz là phân giác:
xOz = zOy

Đặt mỗi góc = t:
t = 3t − 20
2t = 20
t = 10°

Vậy góc xOy:
10° + 10° = 20°
Hình 9

Hai đường thẳng song song

a ∥ b

→ Góc đồng vị bằng nhau
→ Góc so le trong bằng nhau
→ Góc trong cùng phía bù nhau
Câu 1 — So le trong bằng nhau
Nếu một cặp góc so le trong bằng nhau thì hai đường thẳng song song.
Câu 2 — Góc đồng vị 65°
Hai góc đồng vị bằng nhau.
Góc còn lại = 65°.
Câu 3 — Trong cùng phía 70°
Hai góc trong cùng phía bù nhau:
x + 70° = 180°
x = 110°
🔥 Câu 4 — Tìm x và chứng minh song song

Hai góc so le trong:
3x + 10° và 5x − 30°

Vì so le trong bằng nhau:
3x + 10 = 5x − 30
2x = 40
x = 20

Hai góc bằng:
3×20 + 10 = 70°

Hai góc so le trong bằng nhau nên hai đường thẳng song song.
